```
━━ WHAT IT IS ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Put a website, an image, a video or a document in front of a
  fruit fly. ExploreFly runs it through a simulated compound eye,
  propagates the signal through the actual wiring of a male fly's
  central nervous system, and reads the neurons that drive the
  body to tell you where the fly wants to go.

  The brain on screen is not a model of a brain. Every dot is a
  real neuron, at the position it was imaged.
```

```
━━ THE MODEL ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  one node   = one cell type on one side of the body
  inputs     = its 40 strongest, signed by the neurotransmitter

  τ  · dr/dt = −r + [ tanh( g · Σ wᵢ·sᵢ·rᵢ + I − a − θ ) ]₊
  τₐ · da/dt = k · r − a

  g ▸ 3.2    τ ▸ 45 ms    τₐ ▸ 1.2 s    step ▸ 2–5 ms at 30 Hz

  → wiring, not dynamics: no neuromodulation, no gap junctions,
    one individual. Qualitative answers to circuit questions.
```
